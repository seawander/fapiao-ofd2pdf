## Development setup

```bash
git clone https://github.com/seawander/fapiao-ofd2pdf.git
cd fapiao-ofd2pdf
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest
```

Optional image support: `pip install -e ".[image,dev]"`.

## Tests

- Run the whole suite with `pytest`.
- CI runs on **macOS + Ubuntu** and **Python 3.9 + 3.12**; please keep it green.
- macOS-only tests skip automatically on other platforms.
- The test fixture `tests/data/sample.ofd` is synthetic and generated by
  `python tests/make_sample.py` — regenerate it if you change the fixture.

## Guidelines

- Keep changes small and focused; one topic per pull request.
- Match the existing code style; **do not add comments unless they add value**.
- Avoid new runtime dependencies unless clearly justified.
- Add or update tests for behaviour changes.
- Never commit personal documents. `*.ofd` files at the repository root are
  git-ignored for this reason — use the synthetic fixture instead.

## Reporting bugs

Please include:

- your OS and Python version, and the output of `pip show pymupdf`;
- the exact command or Python snippet you ran;
- what you expected and what happened;
- if possible, a **redacted** sample (never upload a real invoice or document
  containing personal data).
